# `1133_generation_limits`: クエスト敵の水増しを抑え、大規模生成の出力枠を広げる

クエストジェネレータが敵を水増しし続けるのを抑え、
ワールドマップ／クエスト／要約など大きな JSON を吐く生成では出力トークン枠を広げる。

自前プロキシの Instantale プロファイル相当のうち、**上限まわりだけ**をプロセス内でやる。
討伐クエスト3件の分割生成は [`1134_quest_split_generation`](../1134_quest_split_generation/DOC.md)。

## 何をするか

**敵の水増し抑制（既定 ON）**

- 曖昧な「normal2-3種を必ず…」を上限付きの指示へ置換
- `【出力上限・終了規則】` を追記
- `structure` が dict スキーマのとき `enemies.maxItems`（既定 6）を付与

**大規模生成の出力枠（既定 ON）**

- ワールドマップ／クエストジェネレータ／TRPG要約を検知し、
  `max_tokens`（ローカルは `n_predict` 等）を既定 **32768** まで引き上げ

効いているかは `out\generation_limits.log` で分かる。

| 設定 | 意味 |
|---|---|
| この MOD を使う | 既定 ON |
| クエスト敵の水増しを抑える | 既定 ON |
| 大規模生成の出力枠を広げる | 既定 ON |
| 大規模生成の出力トークン上限 | 既定 32768 |
| enemies 配列の maxItems | 既定 6 |
| ログに残す件数 | 既定 20 |

#### 困ったとき

- 出力枠を広げても遅い／落ちる → 上限を下げるか OFF。窓や VRAM 不足の症状
- 敵がまだ多い → 分割生成 MOD（`1134_`）も入れる。3件一括の失敗とは別問題
