# `1134_quest_split_generation`: 討伐クエスト3件を1件ずつ生成する

ゲームがクエストジェネレータで `quest_1` / `quest_2` / `quest_3` を一度に
求めているとき、呼び出しを3回に分け、毎回1スロットだけ生成してから結合する。

自前プロキシの分割生成と同じ狙い。敵の水増し抑制や出力枠の拡大は
[`1133_generation_limits`](../1133_generation_limits/DOC.md) 側。

## 何をするか

- system に「クエストジェネレータ」があり、スキーマに `quest_1..3` が揃っている要求だけ対象
- 各スロットで「3つ→1つ」に文言を直し、要件行を当該スロットだけ残す
- OpenAI 互換経路では送信直前の `response_format` を1スロット化
- ローカル llama.cpp では `chat` の `format` を1スロット化
- 失敗したスロットは設定回数まで再試行

効いているかは `out\quest_split_generation.log` の `split #N` で分かる。

| 設定 | 意味 |
|---|---|
| この MOD を使う | 既定 ON |
| 1スロットあたりの再試行回数 | 既定 3 |
| ログに残す分割の件数 | 既定 30 |

#### 困ったとき

- 分割されない → 対象はクエスト3件一括だけ。単発ランダムクエストやワールドマップは通らない
- スロットが何度も失敗する → 再試行を増やすか、`1133_` の敵抑制も入れる
- `1133_` より前に読み込むと、分割後の各回に敵抑制が載りにくい。`after` で `1133_` の後になる
