# `404_party_talk`: パーティーメンバー全員と話す

素のゲームの会話は常に1対1で、仲間を連れていても話せるのは1人ずつ。
`403_` を入れれば会話相手が同行者を認識するようになるが、
同行者は黙って立っているだけで、こちらの発言に横から口を挟むことはない。

この MOD は、「会話する」を押した先の相手一覧に「パーティーメンバーと話す」を1つ足す（「やめる」の手前）。
その場に NPC が居なくて「会話する」自体が無いときは、こちらで「会話する」を足し、
押すと「パーティーメンバーと話す」と「やめる」だけの一覧を開く。
押すと仲間から1人が選ばれ（ランダム）、その相手との普通の会話に入る。
違うのはその会話の間だけで、こちらが一言喋るたびに仲間全員がそれぞれの立場で反応する。

```
「そうだろぉ？お前の射撃も凄いと思ってるけどな、俺は」
アリス・スミス: あら、嬉しいこと言ってくれるのね。（嬉しそうに微笑み、親しげに肩を寄せてくる）
ハナ・ミヤビ: ……非効率な誉め合いです。射撃精度と物理破壊力には相関関係がありません。
```

- 選択肢が出るのは仲間が2人以上のとき。1人なら普通の会話と変わらないので出さない
- こちらの1発言を1ラウンドとし、1ラウンドに各仲間は最大1回しか反応しない。
  反応しない仲間がいてもよく、台詞の代わりに（銃を磨いている）のような行動描写だけでもよい
- 最初に選ばれた1人（アンカー）は本体の会話相手なので毎ラウンド必ず先頭で反応する。
  他の仲間はその後に順に表示される
- 立ち絵は参加者全員が横に等間隔で並ぶ（既定は画面幅の 0.32〜0.68 の範囲。2人なら 0.32 と 0.68、3人なら 0.32・0.5・0.68。名簿順）。
  両端は設定で動かせる。左の選択肢の列（〜0.2）と右の仲間欄（0.78〜）に掛からない値が既定
  本体の相手枠はアンカーのまま位置だけずらし、他の仲間ぶんは同じ形の枠を足す。
  会話を終えると枠は消え、相手枠の位置も戻る。
  設定「仲間の立ち絵を並べる」を切ると、喋った人物へ立ち絵が切り替わり、終わるとアンカーへ戻る
- 仲間の人物像は、ゲーム自身の設定に加えて `311_`（本人の現在像・プレイヤー観）と
  `403_`（仲間同士の関係）の記録をプロンプトへ載せる
- パーティ会話の記憶は `state\party_talk_memory\<世界名>.json` に1ファイルで蓄積する。
  各ラウンドは台本の追記だけ（LLM なし）。要約は会話・物語LLMへ短く注入する
- 本体履歴には仲間の台詞を積まない（誤帰属を防ぐ）。パーティー会話中は 311/403 の
  自動抽出は止まる。会話が終わったときに 311 一括抽出と 403 関係抽出を1回ずつ積む。
  終了ボタンを押した時点で台本を写す。本体の終了要約が履歴を空にしても、
  写しとファイルの追記へ落ちる（空の履歴から組み直さない）
- 会話は本体のものなので、終わり方も本体と同じ。「会話を終了する」は
  この MOD の間だけ「話し合いを終了する」と表示される
- この会話の間は「ここで別れる」（`302_`）と「＜アイテムの受け渡し＞」（`402_`）は出ない。
  どちらも相手1人との会話に向けた選択肢で、全員と話している場面では相手が定まらないため
- この会話では自由記述で何を頼んでもゲームの状態は変わらない
  （移動・売買・戦闘・アイテム操作は起きない。仲間が態度で応じるだけ）

仲間全員に反応させる LLM 呼び出しは会話の LLM を差し替える形で、
本体の1対1の呼び出しは走らない（1発言につき返答 LLM は通常1回。形式が壊れていれば同じプロンプトで1回だけ呼び直す）。
会話中の 311/403 抽出は走らない。終了時に 311 一括と 403 が裏で1回ずつ追加される。
記録は `out\party_talk.log`。`output_data\` には `mod_party_talk` の名で残る。
パーティ会話の記憶は `state\party_talk_memory\<世界名>.json`。

| 設定 | 意味 |
|---|---|
| 会話開始の選択肢 | 既定「パーティーメンバーと話す」 |
| 会話終了の選択肢 | 既定「話し合いを終了する」 |
| 参加NPC上限 | 既定 6。名簿の先頭から数える |
| LLMへ渡す直近の会話数 | 既定 12 ラウンド（こちらの発言の回数で数える。仲間の台詞が何行あっても減らない） |
| 仲間の立ち絵を並べる | 既定 入。切ると喋った人物へ切り替える方式 |
| 立ち絵の左端の位置 / 右端の位置 | 既定 0.32 / 0.68（画面幅に対する比。両端の仲間の中心）。人物が UI に掛かるなら内側へ、間隔が詰まりすぎるなら外側へ |

#### 制約

- **本体の会話要約・ライフログには仲間の台詞が載らない。** 仲間の台詞は本体の履歴に積まず、この MOD の側で控える。
  積むと本体の `conversation_history_to_text` がすべてをアンカーの発言として描くため。
  `311_` / `403_` の記憶更新は会話終了時に、終了ボタン時点の写し（無ければファイルの台本）経由で1回ずつ行う
- 終了時の抽出は裏のワーカー。返答 LLM のあとに人数倍の抽出は積まない
- `311_` / `403_` が無いときはプロンプトへの読み込みも分配も黙って省略する
- `317_reputation` などが会話の LLM へ差し込んでいるものは、この会話では載らない
  （差し替えの外側に居て素通ししない）。載せたければこの MOD のプロンプトへ足す
- 選択肢が出るのは「会話する」を押した先の相手一覧だけ。根のメニュー・宿屋の部屋選び・宿泊中・
  戦闘中・依頼一覧には出ない。ギルドの「冒険者達と話す」の一覧は同じ形だが出さない（`320_` の募集ボタンと同じ見分け方）
- NPC 不在の根のメニュー（出口はあるが「会話する」が無い画面）には自前の「会話する」を末尾に足す。
  本体の「会話する」が在る画面には足さない。会話中・戦闘中・ポップアップ中も足さない
  （店を出た後も残る `in_shopping` は見ない）
- 本体の「会話する」の一覧に相手が居なくても（「やめる」だけ。ギルドなど）「パーティーメンバーと話す」は出る
- LLM が返す名前は参加者の名前と突き合わせ、居ない人物と2回目の反応は落とす（ログに `dropped=` で残る）。
  `・` と `_` など区切りの揺れは正規化して引き当て、表示は参加者側の表記に揃える
- モデルが statement 末尾へ書いた書式残骸（`】 , {` や `{"speaker` の断片）は末尾だけ落とす。
  空になった要素は捨てる。形式が壊れていれば同じプロンプトで1回だけ呼び直す
- 立ち絵の無い仲間は並べない（素のゲームでは起きない。セーブを手で壊した場合の話で、この MOD は面倒を見ない）
- 並べている間にキャラクターシートを開くと、右側の自分の立ち絵と仲間の枠が重なる（シートの窓が上に載るので実害は薄い）

#### 困ったとき

| 症状 | やること |
|---|---|
| 選択肢が出ない | 仲間が2人未満か、「会話する」の相手一覧を開いていない。`out\party_talk.log` に `added ... to the talk list` が無ければ一覧と見なしていない（`DisplayTalkChoice.execute` を通っていないか、別の画面の spec が混ざっている） |
| NPC 不在なのに「会話する」が出ない | `party_talk.log` に `added own '会話する'` が無い。`own '会話する' withheld: ...` が出ていればその旗（戦闘・会話・ポップアップ）が立っている。何も無ければ出口（`MovePhaseManager`）の無い画面 |
| 押しても会話に入らない | `party_talk.log` の `pressed` の次を見る。`ERROR ConversationStartManager not found` なら注入が `__main__` の前 |
| 仲間が誰も反応しない | `round N anchor=... extras=[] dropped=[...]` を見る。`nonparty:` が並ぶなら LLM が別名で返している。`matched:` が出ていれば揺れは引き当て済み。`retry 1:` のあと `extras=[]` なら2回とも壊れている |
| 返答が途中で切れた／JSONや中国語メタが混ざる | モデルが statement へ `】 , {` や `」}]}` 以降のメタ説明を書き足していた。`sanitized:` が出ていれば落としている。残骸が残るなら `output_data/.../mod_party_talk/` の生応答を見る |
| 1発言の待ちが長い | 形式破損で1回呼び直している（`retry 1:`）。壊れていなければ1回のまま |
| 仲間の立ち絵が黒い | 立ち絵の切り替えは Clock 経由で行っている。出るなら `modloader.log` に `party talk:` の行があるか |
| 立ち絵が並ばない | `party_talk.log` に `portrait added` が無い。`WARN character_image not found` なら HUD の相手枠が引けていない |
| 会話を終えても仲間の枠が残る | `portraits removed` が出ていない。`modloader.log` の `party talk: cannot remove` を見る。タイトルへ戻れば消える |
| 会話を終えても npc_profiles が変わらない | `party_talk.log` の終了付近を見る。`memory split skipped: empty transcript` は台本を取り逃がしている。`memory split:` のあと `npc_profile.log` の `extract queued (group)` を待つ |
| パーティー会話中に「ここで別れる」「＜アイテムの受け渡し＞」が出る | `party_talk.log` に `hid the party-only choices` が無い。302 / 402 の印のキーが変わっている（`HIDDEN_MARK_KEYS`） |
| `structured -> None; fallback no-structure` | 構造化出力を使えないモデル。`no-structure` で読めていれば動く。読めなければ `WARN fallback unreadable` |

## 出どころ

MoririnJP 氏の試作（`404_party_talk` v6）を提供してもらい、
立ち絵の切り替えと会話履歴の扱いを直したうえで、立ち絵を並べる方式と選択肢の出し方を足した。
実機での確認の記録は VERIFICATION_LOG.md §2.78、残る確認項目は VERIFICATION.md §3.41。
